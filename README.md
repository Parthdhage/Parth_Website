# Parth Dhage — Portfolio

A static personal portfolio built with HTML, CSS, and JavaScript.

## Repository layout

    index.html    Page content and metadata
    style.css     Layout and visual styles
    script.js     Browser interactions

## Preview locally

No package installation is required. From the repository root, start a local static server:

    python -m http.server 8000

Open http://localhost:8000 in a browser. You can also open index.html directly, though a local server provides more consistent browser behavior.

## Deployment

The site is static and can be hosted by any provider that serves HTML, CSS, JavaScript, and static assets. Keep asset paths relative to the repository root when deploying.
